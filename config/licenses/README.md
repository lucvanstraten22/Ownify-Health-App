# Licence texts

The texts Instellingen › Over de app › Licenties shows (lib/legal.php):

- `apache-2.0.txt` — as AndroidX ships it inside its artifacts
  (`META-INF/androidx/**/LICENSE.txt`).
- `bsd-3-clause.txt` — as Health Connect's
  `connect-client-external-protobuf-1.1.0.jar` ships it.
- `mit.txt` — the standard MIT licence text (checker-qual's POM names MIT).
- LGPL-2.1 is read from `includes/vendor/phpmailer/LICENSE`, PHPMailer's own copy.
